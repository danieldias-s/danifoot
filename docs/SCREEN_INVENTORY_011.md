# Inventário Completo de Telas e Matriz de Diagnóstico — Tarefa 011 (`ELIFOOT_COMPLETE_GAMEPLAY_UI_011`)

## 1. Visão Geral da Arquitetura de Interface
O cliente Flutter (`client/elifoot_flutter`) concentra a navegação clássica em `ElifootShellScreen` (`lib/main.dart` + `lib/shell_actions.dart`) e o módulo de rankings/histórico/premiações em `lib/player_rankings.dart`, comunicando-se exclusivamente com os endpoints REST oficiais e o Hub SignalR `/hubs/gameroom` via `ElifootApiClient` (`lib/api_client.dart`).
